# Content automations

Tools I use to produce video content for @thechosenone and @reelworks.studio.

| Project | What it is |
|---|---|
| `remotion/` | Programmatic video rendering with Remotion |
| `VeryWiseTime/` | "Wise time in my life": short PS2-cutscene-style animated videos in English and Hungarian |
| `GTAVI clipping/` | Clip cutting pipeline |
| `dashboard/` | Content dashboard |
| `tools/` | Helper scripts |

The code is being moved in from my local projects folder.
